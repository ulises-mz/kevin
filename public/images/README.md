# Imágenes Necesarias

Esta carpeta debe contener las siguientes imágenes para la landing page de Transportes GEMA:

## Imágenes Requeridas

1. **logo.svg** (o logo.png)
   - Logo de Transportes GEMA
   - Dimensiones recomendadas: 200x60px
   - Formato: SVG preferido, o PNG con fondo transparente

2. **og-image.jpg**
   - Imagen para compartir en redes sociales (Open Graph)
   - Dimensiones: 1200x630px
   - Debe incluir el logo y texto representativo

3. **hero-truck.jpg**
   - Imagen de fondo para la sección Hero (opcional)
   - Dimensiones recomendadas: 1920x1080px
   - Alta calidad, enfoque en camiones de carga

4. **fleet-1.jpg, fleet-2.jpg, fleet-3.jpg, fleet-4.jpg**
   - Fotos de los camiones de la flota
   - Dimensiones recomendadas: 800x600px
   - Fotos reales de los equipos de Transportes GEMA

## Notas

- Todas las imágenes deben estar optimizadas para web (comprimidas)
- Formatos recomendados: JPG para fotos, PNG para gráficos con transparencia, SVG para logos
- Next.js optimizará automáticamente las imágenes al usar el componente next/image
- Los placeholders actuales (emojis) pueden reemplazarse con estas imágenes reales

## Optimización

Para optimizar las imágenes antes de subirlas:
- Usar herramientas como TinyPNG, ImageOptim, o Squoosh
- Mantener la calidad visual pero reducir el tamaño del archivo
- Objetivo: menos de 200KB por imagen cuando sea posible
